# 미소금융대구중구법인 홈페이지 이미지 적용 추진계획서

**검토 기준일**: 2026-07-25
**검토 대상**: 「항목별 이미지 제작 및 적용 계획서」(이하 "원 계획서") 대비 실제 저장소(`leejongin1124/miso-daegujunggu-google`) 코드 및 자산 현황
**검토 방법**: 원 계획서에서 제시한 메뉴별 이미지 항목을 코드(`src/components/*`, `src/types.ts`, `src/App.tsx`)와 `public/` 자산 실물 대조

---

## 1. 종합 결론

**이미지 추가는 기술적으로 전부 가능하다.** 다만 원 계획서가 제안한 항목 중 상당수는 이미 코드에 구현되어 있고, 남은 항목은 두 가지 성격으로 갈린다.

1. **코드 작업만으로 즉시 반영 가능한 항목** — 이미지 자산이 이미 있거나, 자산 1장만 확보되면 기존 컴포넌트 구조에 바로 끼워 넣을 수 있는 항목 (예: `products-bg.webp` 교체, Product 타입에 이미지 필드 추가)
2. **코드 작업만으로는 완결되지 않는 항목** — 실제 인물·건물·행사 사진, 또는 원 계획서의 "생성형 이미지" 지침을 통과한 상황 이미지 자체가 아직 존재하지 않아, **자산이 먼저 확보되어야 코드에 반영할 수 있는 항목**

이 세션에는 이미지 생성·촬영 도구가 없으므로, 2번 항목은 이번 작업 범위에서 "코드 슬롯 준비"까지만 가능하고 실제 이미지 확보는 법인 측 협조(촬영 또는 검수된 이미지 제공)가 선행되어야 한다. 아래 표에서 이를 구분해 표시한다.

## 2. 판정 기준

| 판정 | 의미 |
| --- | --- |
| **A. 완료** | 원 계획서의 요구사항을 코드가 이미 동일하거나 동등한 방식(HTML/CSS/SVG 대체 등)으로 충족하고 있음. 추가 조치 불요. |
| **B. 자산 확보 시 즉시 반영** | 코드 구조는 이미 이미지 슬롯을 갖추고 있어, 규격에 맞는 이미지 파일 1장만 있으면 파일 교체·경로 추가만으로 반영 가능. |
| **C. 코드+자산 모두 필요** | 이미지 슬롯 자체가 코드에 없어 타입 정의·컴포넌트 수정과 신규 이미지 자산이 함께 필요. |
| **D. 실물 확보 선행 필수** | 실제 촬영(대표자, 건물, 행사 등)이 전제 조건이라 이미지 생성/코드 작업으로 대체 불가. 법인 협조 없이는 진행 불가. |

## 5. 재정렬된 추진 순서 (코드 실태 기준)

원 계획서의 1~3단계 구분은 "아직 아무것도 없다"는 전제였지만, 실제로는 인포그래픽·벡터 항목 대부분이 이미 끝나 있으므로 다음과 같이 재정렬하는 것이 효율적이다.

**즉시 착수 가능 (자산만 도착하면 당일 반영, 순수 코드 작업)**
1. 미소금융이란 전용 배경 이미지 교체 (`App.tsx:121` 경로 1줄 수정)
2. 상품 대표 이미지 슬롯 코드 준비 (`types.ts` 필드 추가 + `ProductSection.tsx` UI 삽입) — 이미지 4장 도착 즉시 반영 가능하도록 선작업 가능
3. 사례 이미지 대체텍스트를 장면 설명형으로 교체, `<img>`에 width/height 명시 (접근성·성능 퀵윈, 신규 자산 불요)
4. 불법사금융 예방 통합 일러스트 SVG 슬롯 준비

**법인 협조가 선행되어야 진행 가능 (실물 촬영/제공 필수)**
1. 대표자 인사말 사진 — `ceo-photo.jpg` 확보 전까지 현재 빈 박스 노출 지속
2. 건물 외관·출입구·주차장·엘리베이터·4층 현판 사진
3. 공식 행사·협약식·수상 사진 (연혁 콜라주용)

**신규 이미지 자산 제작이 선행되어야 진행 가능 (실사 또는 검수된 생성형 이미지)**
1. 대출상품 4종 대표 이미지
2. 상담사례 이미지 8종의 규격·색보정 통일 리터치(이미 있는 이미지의 품질 개선 차원)
3. 공지사항 유형별 썸네일 세트

## 6. 이번 세션에서 처리하지 않은 이유

이 환경에는 사진 촬영이나 이미지 생성 기능이 없어, 원 계획서 3.2절이 규정한 "실제 촬영만 허용" 항목과 "생성형 이미지 사용 가능" 항목의 실물 파일 자체를 만들어낼 수 없다. 따라서 이번 산출물은 **코드가 이미지 자산을 받아들일 준비가 되어 있는지에 대한 실행 가능성 진단**으로 범위를 한정했다. 실제 이미지 슬롯 코드 수정(`types.ts`, `ProductSection.tsx`, `NoticeSection.tsx` 등)이나 대체텍스트·width/height 개선은 위 5장의 우선순위에 따라 별도 작업 요청 시 바로 진행 가능하다.
