# 미소금융대구중구법인 홈페이지 분석·개선 계획서

- **대상 URL:** https://misodaegu-or-kr.vercel.app/
- **코드베이스:** React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + React Router 7
- **분석일:** 2026-08-04
- **범위:** 라이브 사이트 점검 + 소스 코드 전수 리뷰
- **본 문서 성격:** 실행(구현) 없이 진단·우선순위·개선 방향만 제시

---

## 1. 총평

사이트는 공익·서민금융 기관에 맞는 메뉴 구조(법인소개 / 대출상품 / 신청안내 / 상담사례 / 알림마당)와 보안 헤더(CSP, HSTS 등)를 갖추고 있다. 다만 **홈(`/`)이 Hero + Footer만으로 구성되어 본문이 비어 있고**, Hero에 **누적 실적 0건/0억이 잠깐 노출**되며, **공식 도메인(`misodaegu.or.kr`) DNS가 응답하지 않는** 상태가 확인된다. 공익금융 사이트로서 신뢰·가독·접근성 측면에서 반드시 손볼 항목이 있다.

## 2. 반드시 수정해야 하는 곳 (P0)

| # | 문제 | 근거 | 권장 조치 |
|---|------|------|-----------|
| P0-1 | **홈 본문 부재** | `App.tsx`에서 랜딩은 `<Hero />`만 렌더. `LandingSummary`는 “현재 비노출” 주석만 있고 미사용. 스크롤 시 Footer만 노출 | 홈에 요약·상품·절차·공지·오시는 길 등 본문 섹션 복원 또는 신규 구성. SEO·첫인상 모두에 직결 |
| P0-2 | **실적 카드 초기값 `0건` / `0억 원 돌파`** | `Hero.tsx`에서 `statsInView`가 300ms 후 true. 그 전·크롤/느린 기기에서 0 노출. 라이브 HTML 스냅샷에서도 `0 건` / `0억 원 돌파` 확인 | 초기값을 최종 목표치(또는 `—`)로 두고 카운트업, 또는 SSR/정적 수치로 즉시 표시 |
| P0-3 | **공식 도메인 미응답** | `https://misodaegu.or.kr` 접속·DNS 조회 실패. 코드·OG·canonical·sitemap·JSON-LD는 전부 `misodaegu.or.kr` 기준. 실제 접속은 `*.vercel.app` | 도메인 DNS/SSL/Vercel 연결 점검. 미연결이면 미리보기·검색·카카오 OG가 깨짐 |
| P0-4 | **연혁 “홈페이지 개설 예정”(2026.08.03)** | `AboutSection.tsx` `status: 'planned'`. 분석일(08.04) 기준 사이트는 이미 공개 | “개설”로 확정하거나 실제 오픈일로 수정 |
| P0-5 | **`/about/about-miso` 앵커 없음** | `ABOUT_SECTIONS`·`SECTION_MAP`에 `about-miso` 존재. 실제 DOM은 `id="ceo-greeting"`만 렌더. Header에도 해당 메뉴 없음 | 별도 섹션을 만들거나 라우트/매핑에서 제거해 IA 일치 |
| P0-6 | **Hero 클릭 카드 키보드 접근 불가** | `href` 없는 카드는 `motion.div` + `onClick`만 사용(오시는 길·상품·신청). Tab/Enter로 실행 불가 | `<Link>` / `<button>` / `<a>`로 교체, 포커스·aria 확보 |
| P0-7 | **「미소금융이란」페이지 배너 제목 오류** | `MisoIntroRoute`의 `SectionPageShell title="신청안내"`, 메타는 “미소금융이란”, 본문도 제도 소개 | 배너 제목을 「미소금융이란」으로 통일 |

### P0 수정 순서 제안

1. 도메인·DNS·canonical 정합성 (P0-3)  
2. Hero 0건 노출 제거 (P0-2)  
3. 연혁·미소금융이란 문구 정정 (P0-4, P0-7)  
4. `about-miso` 라우트/앵커 정리 (P0-5)

## 5. 디자인 개선 방안 (실행안이 아닌 방향)

현재 톤은 teal/emerald + 영상 Hero + 카드형 퀵메뉴다. 공익금융·비영리 기관으로서 **신뢰·안정·가독**을 우선하고, 과도한 모션·깜박임은 줄이는 방향이 맞다.

### 5.1 Hero (첫 화면)

| 현상 | 개선 방향 |
|------|-----------|
| 브랜드명`(사)미소금융대구중구법인`이 헤더에만 있고, Hero 헤드라인이 더 강함 | Hero에 **브랜드를 히어로급**으로 배치. 헤드라인은 보조 |
| 첫 뷰포트에 순환 칩 + 긴 기관 소개 + 통계/CTA 카드가 동시에 존재 | **한 구성**: 브랜드 · 한 줄 메시지 · 짧은 보조문 · CTA 그룹 · 배경 영상/사진. 통계·주소는 다음 섹션 |
| 카드 위 ring/깜박임 어텐션 | 금융 톤에 맞게 **짧은 1회 강조 또는 정적 hover** |
| 카드 `truncate`로 문구 잘림 | 2줄 clamp 또는 타이포 스케일 조정 |
| 영상 대비 불안정 | 좌측(텍스트) 국소 딤, 우측은 영상 유지 |

### 5.2 홈 전체 구성 제안 (와이어 수준)

```
[고정 헤더]
[Hero: 브랜드 + 한 줄 약속 + 전화/신청 CTA + 풀블리드 영상]
[신뢰 스트립: 누적 실적(출처 포함) — 카드 과다 지양]
[대상별 진입: 청년 / 영세자영업 / 취약계층 → 상품]
[신청 3~4단계 요약]
[최신 공지 1~2건 + 불법사금융 안내]
[오시는 길 요약 + 전화]
[Footer]
```

- 섹션당 **목적 1개 · 헤드라인 1개 · 짧은 보조문**  
- 장식용 카드·이모지 그리드·stat strip 남용 지양  
- `LandingSummary`의 이모지 카드 패턴은 기관 톤과 맞지 않으면 **아이콘+텍스트 리스트/링크로 재설계**

### 5.3 서브페이지·브랜드 시스템

1. **색:** 이미 정의된 `miso-blue` / `miso-navy`(`index.css`)를 본색으로 쓰고, teal 남용·다색 아이콘 팔레트는 축소  
2. **타이포:** Pretendard 유지는 적합. 굵기 단계(black/extrabold) 과다 사용을 정리해 위계 단순화  
3. **SectionPageShell:** `md:whitespace-nowrap` 설명문은 줄바꿈 허용. 영문 eyebrow는 유지하되 한국어 제목이 주인공  
4. **모션:** 진입 fade 2~3곳 + CTA hover 정도. 탭 자동 순환·숫자 과장 bounce·무한 chevron은 축소  
5. **상담사례:** 과도한 카드 그림자보다 사진·인용·결과 한 줄의 스토리 중심  
6. **다크 푸터**는 유지 가능. 본문은 밝은 배경 + 충분한 여백으로 **공공기관 신뢰감** 유지

### 5.4 모바일

1. 헤더 로고+부제 길이로 가로 압박 → 부제는 `sm` 이상만 또는 한 줄 축약  
2. Hero 카드 2×2는 유지하되 터치 타깃·줄바꿈 점검  
3. 상품 페이지 자동 탭 전환은 모바일에서 특히 방해 → 제거 권장
